# Reading Companions

Interactive maps that travel alongside a book — open any folder’s `index.html` in a browser.

## Companions

- **[The Wide Wide Sea](wide-wide-sea/)** — Hampton Sides’s *The Wide Wide Sea*: John Webber’s pictures along Cook’s third voyage, 1776–1780. Live at [wide-wide-sea.ar.io](https://wide-wide-sea.ar.io/).
- **[Empire of Blue Water](empire-of-blue-water/)** — A campaign atlas for Henry Morgan’s Caribbean: privateer bases, Spanish ports, and the raids that made him famous.
